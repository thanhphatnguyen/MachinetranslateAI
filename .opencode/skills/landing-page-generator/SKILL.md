# Landing Page Generator

A skill for creating high-converting landing pages with professional templates, best practices for conversion optimization, and a structured workflow.

## When to Use This Skill

Use this skill when users want to:
- Create a new landing page from scratch
- Generate a sales page, squeeze page, or capture page
- Build a product landing page
- Get conversion optimization advice
- Need responsive, mobile-friendly page layouts
- Want templates for specific industries (SaaS, e-commerce, local business, etc.)

## Workflow

### Step 1: Gather Requirements

Ask the user about:
1. **Purpose**: What is the landing page for? (Lead capture, product sale, webinar registration, app download, etc.)
2. **Target Audience**: Who is this page for? (Demographics, pain points, desires)
3. **Product/Service**: What are they promoting? (Features, benefits, pricing)
4. **Brand Style**: Colors, tone (professional, casual, luxury), existing brand guidelines
5. **Call to Action**: What should visitors do? (Sign up, buy, download, contact)
6. **Technical Preference**: Plain HTML/CSS, React, Vue, or specific framework?

### Step 2: Select Template Strategy

Based on the purpose, recommend and implement the appropriate structure:

**Lead Capture / Squeeze Page:**
- Attention-grabbing headline
- Subheadline with benefit
- Lead capture form (name, email, maybe phone)
- Compelling CTA button
- Social proof (testimonials, trust badges)
- Minimal navigation (no distractions)

**Product Sales Page:**
- Hero section with product image + compelling headline
- Problem/Agitation section
- Solution/Features section
- Benefits over features
- Testimonials/Case studies
- Pricing/Plans
- FAQ section
- Strong CTA with urgency elements

**Webinar/Event Page:**
- Event title + date/time
- Speaker info
- What attendees will learn
- Registration form
- Limited spots/Urgency elements

### Step 3: Apply Conversion Best Practices

- **Above the fold**: Headline, subhead, CTA visible without scrolling
- **Contrast**: CTA button stands out (different color from background)
- **White space**: Clean, breathable layout
- **Social proof**: Testimonials, logos, user counts, reviews
- **Mobile-first**: Responsive design, touch-friendly CTAs
- **Clear hierarchy**: Headline → Subhead → Benefits → CTA

### Step 4: Generate Code

Create clean, production-ready code:
- Semantic HTML5
- CSS with responsive breakpoints (mobile, tablet, desktop)
- Optional: JavaScript for interactivity (form validation, smooth scroll, animations)
- Accessibility considerations (alt text, ARIA labels, keyboard navigation)

### Step 5: Review and Refine

- Verify all CTAs are prominent and consistent
- Check responsive behavior at different screen sizes
- Ensure form fields are properly labeled
- Validate all links work
- Check color contrast ratios

## Output Format

Deliver to the user:
1. **HTML file** with semantic markup
2. **CSS file** (inline or separate) with responsive styles
3. **Optional JS** for form handling or interactivity
4. **Copy suggestions** - headline, subhead, CTA text options
5. **Optimization tips** - specific to their industry and goals

## Best Practices Reference

- Headline: 6-12 words, benefit-focused, action-oriented
- Subhead: Expand on value proposition, 10-20 words
- CTA Button: Action verb + benefit ("Get My Free Guide" not "Submit")
- Form fields: Only ask for what you need (name + email = highest conversion)
- Images: High quality, relevant, optimized for web
- Loading speed: Keep under 3 seconds, optimize images, minify CSS
- Trust signals: logos, testimonials, security badges, guarantees
